## 演示 1：全新环境部署

1. 展示 ECS 为空（`docker ps` 无容器）。
2. 运行 `deploy/scripts/bootstrap-host.sh`（装 Docker、拉取 compose 文件、写 `.env`）。
3. 在 CodeArts 手动触发流水线，解说阶段：构建 → 单元/集成测试 → 镜像推送 → 部署测试环境 → 冒烟。
4. 浏览器打开测试环境，登录 `student`，进入自习室列表；页脚显示四个服务的 sha@tag 与流水线一致。

## 演示 2：提交触发构建

1. 在分支上把 `apps/m1-seat/src/rooms/room-visibility.ts` 的 `canSeeRoom` 返回值取反，提交并开 MR。
2. 展示 MR 页面"合入条件"中流水线失败，`room-visibility.spec.ts` 红，部署阶段未执行。
3. 修复、推送，流水线转绿，评审通过后合并，测试环境自动更新。
